SPT FIKA FRIEND CLIENT PACK
===========================

Supported system: 64-bit Windows 10 or Windows 11 with SPT 4.1.6 / EFT 0.16.9.40743.

1. Extract the entire ZIP. Do not run the installer from inside the ZIP preview.
2. Double-click OPEN-GUIDE.cmd for the clickable visual guide.
3. Double-click INSTALL-FRIEND-PACK.cmd.
4. Accept the Windows UAC prompt.
   If Windows SmartScreen appears, confirm the ZIP came directly from your host, then choose More info > Run anyway. Do not disable Windows Security.
5. Choose your SPT folder if asked.
6. Open SPT Launcher and add the address supplied privately by the host: https://HOST_ADDRESS:6969
7. Create your own profile. Never select another player's profile.
8. Start the game. Do not run SPT.Server on a client computer.

The installer verifies every file, backs up existing client mods, and restores the backup automatically if installation fails. Details are written to INSTALL-LOG.txt.
